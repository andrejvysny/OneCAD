# Platform icon PNGs

Renders of the macOS light app icon master
(`../brand/svg/app-icon-macos-light.svg`) at each file's pixel size; names are
kept from the retired `src-tauri/icons` set. `master.png` is the 1024 px render,
`32x32.png` is the design's simplified small-size drawing
(`../brand/small/icon_32.png`), and `icon.png` (512 px) is embedded as the
runtime window/dock icon. Do not edit by hand; regenerate with
`scripts/brand-icons.sh`.
