# OneCAD brand masters

Source: claude.ai Design project "Modern CAD Software UI", file
`OneCAD Brand.dc.html`, export `assets/onecad/**`, imported 2026-10-21.
Mark "4c": an isometric cube over its sketch footprint.

## Spec

- macOS 1024 grid: 824 body, 100 margin, built-in drop shadow.
- Field gradient `#2B6BE6` to `#173FA0` (dark `#12213B` to `#080F1D`).
- Solid: top `#FFFFFF`, left `#D3E1FF`, right `#A6C1F5`.
- Sketch `#9BE7FF` (dark `#4FC3FF`). Ink `#1B1D21` / `#F3F4F5`.
- Wordmark: SF Pro, "One" weight 700 + "CAD" weight 300, tracking -2.5%.
- Sizes of 32 px and below use a simplified drawing.

## Files

- `svg/app-icon-macos-light.svg`, `svg/symbol.svg`: verbatim design exports
  (C2PA metadata stripped).
- `svg/document-icon.svg`: composed to the design's structure (page, fold, app
  tile at `translate(317 250) scale(.38)`, tile ids `oc71*`).
- `svg/symbol-dark.svg`: DERIVED, not exported. Symbol geometry recoloured
  with the generator's `profile.glyphDark` palette (sketch `#4FC3FF`, dot
  `#141517`, top `#FFFFFF`, left `#9DB9F0`, right `#5C84D0`). The symbol is
  used alone, without a well.
- `small/`: verbatim design PNGs of the simplified small-size drawing
  (`icon_16`, `icon_32`, `doc_16`, `doc_32`).

Generated by `scripts/brand-icons.sh` (rsvg-convert + iconutil; never edit):

- `macos/OneCAD.icns`, `macos/OneCADDocument.icns`: 16 to 1024 px; 16, 16@2x
  and 32 entries come from `small/`.
- `png/symbol-56.png`, `png/symbol-dark-56.png`: start-screen mark (28 pt @2x).
- `../app-icons/*.png`.

The document icon is staged only; packaging declares no document types yet.

## Not imported

- Horizontal and stacked lockups: SF Pro text whose exact wordmark spacing is
  not reproducible offline.
- Dark and tinted macOS app icons, iPadOS icons and web favicons.
