## 2. Updated findings (Astra, verbatim in substance)

**F2/C1 — open, blocker.** A length floor cannot establish angular quality or prove a singularity. Counterexample: a rational quadratic quarter-circle r = 0.05 mm at X = 1e9 mm between two 100 mm tangent straights, fine tier: chordLength r√2 = 0.070711 mm, chordBound r/√2 = 0.035355 mm, sum 0.106 mm; ρ = 32 mm so 16ρ = 512 mm — the span fails the cone, passes C1, and is emitted as one chord making 45° turns with both neighbours; the curve is G1 with no stationary point. Without translation, r = 2e-5 mm gives length+bound = 4.24e-5 < 0.05/1024 with the same 45° turns, so `/1024` supplies no angular guarantee either. The C1 branch (`CurveSampler.cpp:~816`) sets `Undefined` but not the singular flags. Closure: test turns between FINAL emitted segments as the acceptance predicate — `angle(P32[i]−P32[i−1], P32[i+1]−P32[i]) ≤ angularTolerance` at every regular join, zero encoded chords handled explicitly — exempt only independently established singularities; use a positional floor solely to bound an unresolved region.

Derivation: with an unresolved leaf of chord ℓ and bound b the curve lies within R = ℓ + b of either endpoint (positional enclosure only). For neighbouring chords L−, L+ with angular errors β−, β+ and R < min(L−, L+): observed turn ≤ J + β− + β+ + asin(R/L−) + asin(R/L+), J the genuine tangent jump (0 regular, π cusp). Preserving a cusp and bounding its own turn by 5° are incompatible; for a regular join a sufficient condition is β− + β+ + asin(R/L−) + asin(R/L+) ≤ tol, e.g. with β± = 1.25° in the 5° tier R ≤ 0.02181·min(L−, L+) — a condition on neighbour lengths and margins that neither 16ρ nor /1024 contains. Termination: for a stationary root of order m with restricted-hull bound ℓ + b ≤ K h^m, a positional enclosure ε needs at most ceil(log2(K h0^m/ε)/m) halvings; for C(t) = ((3t−1)², (3t−1)³) with ε = 0.05/1024, 11 halvings suffice — termination for that fixture, not an angular justification of /1024. Scaling: lengths, budgets and K scale with a similarity; angle and neighbour-ratio predicates are invariant; ULP allowances are coordinate-dependent and only power-of-two scaling preserves them.

**F6 — open (arithmetic).** Removing the ratio veto is sound in exact arithmetic, not for all floating-point inputs: P = [(0,0),(0,1),(1,0)], w = [1e-300, 1e300, 1e300] normalises to [0,1,1] (underflow); subdivision produces a left net [(NaN,NaN),(0,1),(1/3,2/3)]; `std::max(worst, NaN)` keeps `worst`, giving a ZERO chord bound; the invalid pole need not be an emitted endpoint; the arithmetic path can emit [(0,0),(1/3,2/3),(1,0)] while the curve approaches (0,1), 0.4714 mm away. Whether OCCT forwards such weights is unverified; the "all positive finite weights" claim is refuted. Closure: validate every generated control net (finite poles, positive finite denominator enclosure); never let non-finite positional arithmetic become angular-only uncertainty. Positional roundoff bound for the certificate: with u = 2^-53, K = d(n+3)+2, g = γ_K, the computed-pole error per axis is ≤ [(2g + u(1+g))/(1−g)]·M_j; for n = 32, d = 32 (K = 1122) the multiplier is 2.492e-13, i.e. ≤ 4.317e-4 mm Euclidean when every |coordinate| ≤ 1e9 mm — conservative, weight-ratio independent (no 1e18 multiplier). Add this enclosure to outward-rounded pole-to-segment distances; comparing against the computed endpoint chord can need twice the enclosure.

**C2 derivation.** Q(t) = G(t) + H(t) with G the retained and H the excluded coefficients; p_min = min retained dot(q_i, d) > 0; s(t) = Σ retained B_i(t) (the retained Bernstein mass — it cannot be omitted, the retained weights no longer sum to one); E = Σ excluded ‖q_i‖ (include coefficient arithmetic uncertainty). On an interval with s(t) ≥ s_min > 0, g = p_min·s_min; if the retained coefficients lie within half-angle β and E < g then angle(Q(t), d) ≤ β + asin(E/g), so `Satisfied` is justified iff β + asin(E/g) ≤ tol/2. If s_min = 0, E ≥ g, or the retained cone already spends the allowance, the calculation supplies no certification and `Undefined` (evidence incomplete, not "the derivative vanishes") is honest. There is no derivation of 1e-9 as a universal "untestable" threshold: use coefficient error bounds and cone margin; a computed floating-point zero is not automatically a proved zero. The 1-vs-39-leaf discontinuity is permissible for a deterministic adaptive sampler with accurate status; report a continuous margin alongside the discrete status; no history-dependent hysteresis (pure-function contract).
