OneCAD — final design · core modeling flow
One shell everywhere: full-bleed viewport, floating Explorer (left, with the workspace switcher on top), floating Inspector (right, only while something is selected), full-width status bar. One toolbar pill whose contents follow the selection: nothing selected → creation and view actions; face, edge, region, sketch line or history feature → only what applies to it, with a removable selection label at its head. Colour isometric icons at 24px; orange = created geometry and previews, blue = sketch / modified. Final: 01a start, floating shell, selection-driven pill (03a is clickable: ⌘1 / ⌘2 toggle the panels), sketch states 04a → 04b, parameter card 05a. Reusable parts: OneCAD Components.
