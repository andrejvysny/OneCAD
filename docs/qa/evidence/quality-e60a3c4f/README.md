# Paused quality-work evidence

This archive records source-specific automated qualification and unsuccessful
Framework geometry diagnostics. Canonical status and remaining work belong to
the ONECAD Plane project. The production tree tested here is commit
`e60a3c4f302ceef479064ef6b9c5e45910afee8a`.

The publication checkpoint retains this archival commit as a historical parent;
its files are not added to the active production tree. `files.json` pins the
retained bytes. The compressed automated archive includes its own hashed file
manifest, exact commands, outcomes and source boundaries. Its exact bytes were
also retained and read back through internal ONECAD-534 comments.

The Framework sources and outputs are private diagnostic experiments using the
pinned public fixture. Attribution and original license terms remain under
`fixtures/public-cad`; see that directory's README and manifest in this commit.
Unsuccessful normalization, algebraic reconstruction and analytic-support probes
remain explicit failures. Neither geometry-policy probes nor STEPCAF transfer
prove source equivalence, persistent identity or a complete native workflow.
Raw BRep operands and compiled diagnostic executables remain local artifacts;
retained reports identify their hashes and extraction provenance. Historical
`/private/tmp` paths identify the executed setup, not portable installation paths.

Release solver samples measure pure solve calls only, with validation outside
the timing span. They are not controlled desktop interaction or presentation
measurements. Current macOS/latest-stable, native GUI, physical input/device,
reference uncertainty, complete Framework history, different-face repair and
controlled performance requirements remain open in Plane.
